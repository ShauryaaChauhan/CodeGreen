Carbon Footprint Tracker 
Ok so, I made this website to help people see how much pollution cars and buses also motorcycles make. I wanted to see if we could show that math in a way that is more sajilo to understand.
so I used the idea of how long it takes for a tree to clean the air 

Pick any two places by just clicking on the map and it draws a line to show the road.
Does the math It checks the distance and multiplies it by how much smoke a car or bus makes.
Power It tells you exactly how many days, hours and minutes one tree would need to breathe in all that Carbon dioxide to clean it up.
